# cure-job command reference

The CLI is `cure-job` (bare name; `${CLAUDE_PLUGIN_ROOT}/bin/cure-job`). The state root is `${CURE_JOB_ROOT:-~/.claude/cure}`.

| Command | Behaviour |
|---|---|
| `cure-job prune` | Removes finished jobs and half-created directories. A `done` job goes once reported and its sessions are removed; an `abandoned` job once its sessions are removed; a `failed` job after `prune.failed-days`. A job named by the `after` of an unfinished job stays. A removed job's worktrees go with `git worktree remove`; its branches stay. |
| `cure-job next --json` | JSON array in lock-rank order. Element: the job's `list --json` row plus `actions` (ordered action names) and `args` (a list parallel to `actions`: `args[i]` holds the args of `actions[i]`, `{}` when it has none). A job with no action is absent. |
| `cure-job list --json` | One row per job: derived state, resources, files, `origin` (bound by `cure-job new`), `open` (count of `## Open` items in `goal.md`), `reported`, `sessions-removed`, `prs`, `ticket`, `ticket-summary`, `branch` (null when the handoff omits it), `workspace` (launch directory), `after` (predecessor id or null), `after-state` (predecessor state, `missing` or `invalid`), and for a `blocked` job `waiting-for`. `phase`: `queued`, `awaiting-approval`, `approved`, `working`, `needs-input`, `done`, `failed` or `abandoned` (null for an `invalid` row). `sessions`: each session kind the job has, mapped to `n`, `session`, `liveness`, `waiting-for`, `run`, `inputs`, `restarts` and `summary` (`{}` for an `invalid` row). |
| `cure-job reported <id>` | Records that the finish message for the job's latest run was sent or printed. |
| `cure-job stop <id>` | Stops the session of the latest run and waits until it is down. Prints the session name, or `<session> not live`; both exit 0. Exit 1 means the session may still be alive. |
| `cure-job approve <id> --by user\|auto` | Records approval of the current `goal.md` digest. `--by` is required. Exit 1 while `## Open` has items. Legal for a job with a `goal.md` and no launched run (`held`, `awaiting-approval`, `approved`). The same digest again writes nothing. Any later edit of `goal.md` revokes it. |
| `cure-job launch <id> [-- --permission-mode <mode>]` | Starts the job session in the worktree of the first repository of `repos`. First creates each missing worktree at `<worktree.root>/<repo name>/<job id>` (`<repo name>`: basename of the git toplevel), detached with no branch at the repository's HEAD, or for a job with `after` at the HEAD of the predecessor's worktree of that repository where it exists. An existing worktree is reused, under the root recorded at the first launch. After `--` only `--permission-mode acceptEdits\|default\|auto`. Passes the worker allow rules `finish <id>`, `claim <id>`, `release <id>`, `config get`, `list`, `finish --help` on `<plugin-root>/bin/cure-job` in `--settings`. A Light or Full job starts with `--agent cure:orchestrator`; a Solo job without `--agent`. A run-1 launch needs `approved`; `awaiting-approval` is refused with a message naming `cure-job approve <id>`. Refuses a job whose session is alive. Refuses a `needs-input` job whose session is listed live with `job <id> is needs-input and its session <name> is live; continue it: cure-job resume <id>`. A `needs-input` job whose session is gone or listed stopped launches. |
| `cure-job close <id>` | Abandons a job. Refuses while its session is alive. |
| `cure-job resume <id> [-- --permission-mode <mode>]` | Needs `needs-input`. Stops the kept session, then runs `claude --bg --resume <session-uuid> "/goal @<goal.md>"` in the job's worktree: same session name, new run. When the session no longer exists, exits 1 with `session <name> no longer exists; start a new run` and starts nothing. Refuses a call from the job's own session (its `CURE_JOB_ID` is `<id>`). |
| `cure-job remove-sessions <id>` | Needs `done` or `abandoned`, else exit 1. Stops each live session of every run, runs `claude rm` on it, prints each removed name. When no session of the job is left listed, records `sessions-removed`. |
