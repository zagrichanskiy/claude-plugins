`sections/` is generated by `scripts/condense-core-guidelines.py`. Each file holds one section:
rule id, title and reason. Stub rules, examples, notes and enforcement text are left out. Do not
edit `sections/` by hand. To update: replace the files in `upstream/`, change the commit above, and
rerun the script.
