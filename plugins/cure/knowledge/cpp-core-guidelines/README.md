# C++ Core Guidelines

`sections/` holds the C++ Core Guidelines condensed to one file per section: rule id, title and
reason. Stub rules, examples, notes and enforcement text are left out. The full upstream text is
not kept in this repository.

`sections/` is generated by `scripts/condense-core-guidelines.py`. The script downloads
`CppCoreGuidelines.md` at the commit above, checks its SHA-256, and writes `sections/`. The download
is not saved. Offline, pass a local copy with `--source <path>`. Do not edit `sections/` by hand.

To update: change the commit and the SHA-256 above, and rerun the script.
